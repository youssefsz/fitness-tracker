Install or update

Visit Android downloads for the current APK and installation steps.

Log a workout

  1. Tap Add entry and choose or create an exercise.
  2. Enter your result and tap Add set for additional sets.
  3. Check the date and save. Open Progress to compare results or History to revisit a workout.

Back up and restore

Open Profile → Your data → Export backup to save a restorable JSON file. Keep it somewhere you can access if you change phones.

Use Import backup → Open JSON file and review the preview. Choose Merge with local data to keep existing records, or Replace all data to restore the backup in their place.

Use Export CSV for spreadsheets. Use JSON for a restore.
