# Local testing preferences

Copy this example to `.local/testing.md` to save choices for your checkout. Git ignores `.local/`. The file is optional. Keep shared commands in [Testing](testing.md).

- Default checks: host only
- Preferred device checks: ask when needed
- Platform: specify Android or iOS if you have a preference
- Test target: paste an ID from `flutter devices` if you want to reuse it

Use a disposable simulator or emulator for test installs. Keep credentials and personal data out of the notes.
