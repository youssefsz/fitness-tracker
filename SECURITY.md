# Report a security issue

Use **Security → Advisories → Report a vulnerability** on GitHub if private reporting is enabled. If that option is unavailable, use the email link on the [maintainer's contact page](https://youssef.tn/#contact) to arrange private disclosure.

Include the affected app version, platform, what may be exposed or modified, and enough detail to investigate. Use fictional data to demonstrate the problem. Avoid including personal workout records, backups, profile photos, or credentials.

Keep the report out of public issues and pull requests while the maintainer investigates. Use the [bug report form](.github/ISSUE_TEMPLATE/bug.yml) for ordinary bugs.
