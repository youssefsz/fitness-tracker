# Product

## Platform

adaptive

## Stack

Flutter and Dart for iOS, iPadOS, and Android.

## Purpose

Fitness Tracker records completed exercise sets and shows how personal performance changes over time. People can log repetitions, duration, weight, or weight with reps. They can correct dates and values and set a personal goal for an exercise.

## Constraints

The app works offline with no account. Overview only reflects recorded activity. The latest set, best set, and daily volume answer different questions. Users can move their records with a JSON backup or export sets for analysis as CSV.
